# Progress — Habit & Goal Tracker

A responsive HTML/CSS/JavaScript habit and goal tracker inspired by the requested 3-level flow:

1. Daily/Home — checkbox based daily progress
2. Monthly — 12-month overview with progress cards
3. Particular Month — daily rows for the selected month

Also included:
- Goals: add, edit and delete goals
- Diaries: create, edit and delete saved notes
- Profile: theme toggle and demo-data reset
- Automatic date-based tracking
- LocalStorage persistence
- Previous dates remain saved; a new day automatically starts with unchecked boxes
- Responsive desktop/mobile layout
- No backend required

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Data
All data is stored locally in browser LocalStorage. For a production app, replace the LocalStorage layer with a backend/database and authentication.
